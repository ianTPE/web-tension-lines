## 這週的對手

- **隱藏或停用把人擋在外面**（4）：accordion:3、copy-button、copy-button:3、toolbar。共同形狀：為了畫面乾淨而用 `display: none`／`disabled` 藏東西，結果把鍵盤使用者或頁內搜尋擋在外面。解法幾乎都不是新功能，而是換一種藏法（`opacity`、`aria-disabled`、`content-visibility`）。
- **焦點或狀態指示消失**（3）：breadcrumbs:2、tabs:2、natural-interactions。`box-shadow`、背景、`clip-path`、`outline: none` 在強制色彩或鍵盤情境下讓「我在哪／選了哪個」消失。
- **重建DOM丟狀態**（2）＋**視覺順序與DOM順序脫鉤**（1）：dynamic-sort、sortable-table、drag-and-drop。同一個主題的三個切面：排序／拖放時要搬真節點，不要重蓋，也不要用 CSS 假裝。關鍵功能 `moveBefore()` 在 Safari 仍不支援。
- **只能 hover 才看得到**（2）：single-line-overflow:2、natural-interactions:2。
- **截字傷可及性**（2）：single-line-overflow、form-factor-adaptation:2。
- **原生元素角色實作不一致**（2）：accordion、navbar:2。兩份指南都點名 `<summary>` 的 button 角色在螢幕閱讀器表現不一致——可以自己實測的對手。
- **版面依賴錯的量測**（2）：navbar（寫死斷點）、form-factor-adaptation（視窗寬度 vs 容器寬度）。
- **手寫焦點管理**（2）：tabs、toolbar:2。兩條的槽 3 都判缺，見下。
- 只出現一次：安裝入口受限、互動中畫面抖動、播報過量、比對錯型別、新功能的副作用、彈出層脫離觸發點、外觀暗示錯的結構、重複內容干擾輔助技術、每顆按鈕手接JS、版面擠壓破壞可讀性。

值得注意的一條：**accordion:2 的對手是新功能本身**。`<details name>`（互斥手風琴，2024 Baseline）被指南建議避用，因為內容會跳出螢幕放大鏡使用者的視野。

戰報分布：勝 16、部分改善 9、僵持 4、缺 1（app-menus 於 2026-11-12 驗證後由僵持改為部分改善）。勝的 16 條大多**不靠新功能**，而是糾正常見錯誤；這期 v1.0.0 的重心是「把元件做對」，不是推新 API。

## 僵持中的線

- install-web-app：`<install>`、`navigator.install()` 沒有任何主要瀏覽器支援。
- breadcrumbs:2：`corner-shape`／`border-shape` 僅 Chrome/Edge。
- tabs、toolbar:2：`focusgroup` 僅 Chrome/Edge 150。

## 本週靈感

這期 30 條線裡有 14 條是**新能力**，其餘 16 條是糾錯。以下是用新能力組出來的點子，屬於發想，不是指南內容。

1. **可重排、但不會重新載入的即時儀表板**
   拖曳重排或依條件排序時，正在播放的影片、即時圖表 iframe、輸入到一半的表單都留在原狀態，只用動畫「走」到新位置。
   用到：`mwg:drag-and-drop`、`mwg:dynamic-sort`（`moveBefore()` + view transitions）。
   限制：Safari 不支援 `moveBefore()`，會退回一般搬動，iframe 會重新載入。
   小 demo：三個 YouTube 嵌入 + 一個計時器卡片，可以拖曳重排，邊播邊搬。

2. **長得像桌面程式的網頁工具**
   選單列（File／Edit／View）加上工具列，整組只有一個 Tab 停點，方向鍵移動，選單黏在按鈕上。幾乎不用自己寫焦點管理。
   用到：`mwg:app-menus`、`mwg:toolbar:2`、`mwg:tabs`（popover、錨點定位、`focusgroup`）。
   限制：`focusgroup` 只有 Chrome/Edge 150，適合先做給自己用的內部工具。
   小 demo：純 HTML 的 Markdown 編輯器外殼，只用鍵盤就能操作完整的選單。

3. **全部摺起來，但 Ctrl+F 找得到的長文件**
   週記、FAQ、規格這類長頁面預設全摺疊，搜尋命中時自動展開，展開有動畫。
   用到：`mwg:accordion:3`（`::details-content`），可搭配 `hidden=until-found` 做分頁版。
   限制：`::details-content` 為 Newly，舊瀏覽器沒有動畫但功能照常。
   小 demo：把這個 repo 的 `lines/` 輸出成一頁，每條線是一個 `<details>`，搜尋對手名稱就會展開。

4. **大量長標籤也不亂的清單**
   檔名列表、分頁列、標籤雲：放不下就截斷，hover 或 focus 時用純 CSS 捲出全文，邊緣淡出跟著捲動消失。
   用到：`mwg:single-line-overflow:2`、`mwg:tabs:3`（scroll-driven animations）。
   限制：scroll-driven animations 2026-10-27 才 Baseline。

5. **一頁裝下自己所有小工具的安裝目錄**（等支援）
   一個入口頁替每個小工具 PWA 各放一顆安裝按鈕。
   用到：`mwg:install-web-app`（`navigator.install()`）。
   限制：目前沒有瀏覽器支援，先記著，等有瀏覽器開始支援時再回來看。
