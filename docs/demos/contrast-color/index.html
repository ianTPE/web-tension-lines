自動對比文字：用 contrast-color()

換背景色，文字自己在黑和白之間選對比較高的那個。適合使用者可以自訂顏色的標籤、主題色，或任何背景色事先不知道的地方。

怎麼做

.chip {
  background-color: var(--bg);
  color: contrast-color(var(--bg));
}

以前要在 JavaScript 裡把顏色轉成亮度、自己算對比，或替每一個主題色手寫一個文字色。換主題或讓使用者自選顏色時，很容易出現看不清的組合。

不支援時

  • 用相對色彩語法（relative color）在 XYZ D65 色彩空間依 WCAG 亮度門檻算出黑或白，效果相同。這頁在不支援的瀏覽器就是這樣做的。
  • contrast-color() 只用在文字等前景色，不要拿來設背景色。
