滑動底線：用錨點定位

點不同的分頁，底線會滑到新分頁下方。位置由 CSS 錨點定位算，不用 JavaScript 量分頁的寬度和座標，分頁文字長短不一也沒關係。

  • 總覽
  • 最近動態
  • 設定
  • 成員與權限管理

目前在「總覽」。

怎麼做

li.active { anchor-name: --active-tab; }

ul::before {
  content: "";
  position: absolute;
  position-anchor: --active-tab;
  inset-block-start: calc(anchor(bottom) + .1lh);
  inset-inline-start: anchor(left);
  inset-inline-end: anchor(right);
  border-block-end: .2lh solid;
  transition: inset .25s;
}

腳本只負責把 active 和 aria-current 換到被點的分頁；底線的位置和動畫全由 CSS 處理。底線只是視覺提示，目前分頁仍要用 aria-current 告訴輔助科技。

不支援時

  • 改用作用中分頁自己的 border-bottom，底線照樣在，只是不會滑動。
  • 系統設定減少動態效果時，底線直接跳到新位置。
