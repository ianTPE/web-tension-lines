對手組戰報圖

這張圖表是一個用 HTML-in-Canvas 做的模組，資料是這個 repo 的 ledger.csv。長條是 canvas 畫的，但每個標籤都是真的 DOM 按鈕，所以可以搜尋、選取、翻譯、用鍵盤操作，整張圖也能直接匯出。

選一個對手組

點圖表裡的標籤，或用 Tab 移到標籤上按 Enter，這裡會列出那一組的線。

試試看

  • 按 Ctrl+F 搜尋「焦點」：命中的字在圖表裡面。一般 canvas 畫的字搜尋不到。
  • 用滑鼠拖曳選取標籤文字、複製；或用瀏覽器的翻譯功能翻成英文。
  • 按 Tab：焦點會依畫面順序走過每個標籤。排序時 DOM 順序也跟著搬，所以順序不會錯開。
  • 「下載 PNG」和「錄 5 秒影片」用的是 canvas 既有的 toBlob() 與 captureStream()，輸出包含標籤文字。

對應的問題線

  • mwg:expose-canvas-content-to-browser-features：canvas 內容對瀏覽器隱形
  • mwg:export-html-media-from-canvas：不用截圖函式庫重畫 DOM
  • mwg:drag-and-drop：排序時搬真節點，視覺順序與 DOM 順序一致
HTML-in-Canvas 目前只有 Chrome 157 起支援。其他瀏覽器會看到 fallback：標籤改用 CSS 疊在 canvas 上，搜尋和鍵盤照常，但匯出的圖片和影片不含標籤文字。資料由 scripts/build_demo.py 從 ledger.csv 產生。
