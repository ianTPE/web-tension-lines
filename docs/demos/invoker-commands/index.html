宣告式按鈕：用 command 和 commandfor

在 HTML 裡寫「這顆按鈕要對哪個元素做什麼」。開關對話框完全不用 JavaScript；自訂指令也只要一個監聽器，不用替每顆按鈕各接一次。

確定要封存嗎？

這個對話框的開與關都沒有寫 JavaScript。
方塊

怎麼做

<button commandfor="confirm" command="show-modal">開啟</button>
<dialog id="confirm">
  <button type="button" commandfor="confirm" command="close">取消</button>
</dialog>

<button commandfor="box" command="--spin">旋轉</button>
box.addEventListener("command", e => { /* e.command === "--spin" */ });

內建指令（show-modal、close、toggle-popover…）完全不需要腳本。自訂指令必須以 -- 開頭，監聽器要掛在目標元素上，因為 command 事件不冒泡。自訂指令沒有內建語意，切換狀態要自己設 aria-pressed。

不支援時

  • 只在瀏覽器沒有 commandForElement 時，才動態載入 invokers-polyfill。
  • polyfill 不會替按鈕處理 aria-expanded 這類狀態，需要時要自己補。
