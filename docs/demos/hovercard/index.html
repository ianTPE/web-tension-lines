預覽卡：用錨點定位

把滑鼠移到下面的連結上，或用 Tab 鍵移過去，等一下就會出現預覽卡。卡片貼在連結旁邊；最右邊那個連結放不下時，卡片會自動翻到左邊。

怎麼做

<a href="/ideas/" interestfor="card-ideas">靈感頁</a>
<div id="card-ideas" popover="hint" class="hovercard">…</div>

.hovercard {
  position-area: block-end span-inline-end;
  position-try-fallbacks: flip-block, flip-inline;
}

interestfor 讓滑過和鍵盤聚焦都能叫出卡片，連結本身成為卡片的錨點；popover="hint" 不會把頁面上其他已開的選單關掉。以前要寫 JavaScript 量座標、處理延遲、偵測有沒有超出視窗。

不支援時

  • 當作漸進增強：觸發元素是一般連結，不支援的瀏覽器照常可以點過去，只是沒有預覽卡。
  • 預覽卡只放「點進去也看得到」的補充資訊，不放只有卡片裡才有的內容。
  • 要在所有瀏覽器都有預覽卡，得依指南分別載入 popover 與 interestfor 的 polyfill；這個 demo 沒有載入。
