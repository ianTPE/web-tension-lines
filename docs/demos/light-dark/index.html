深淺色 token：用 light-dark()

每個顏色 token 一行同時寫好淺色和深色的值。切換下面的選項，整塊區域的背景、文字、品牌色、表單控制項一起換，不用寫兩套樣式或一堆媒體查詢。

配色

帳號設定

這塊區域所有顏色都來自 light-dark() token。


怎麼做

:root { color-scheme: light dark; }

.themed {
  --surface: light-dark(#fff, #1b1d22);
  --brand: light-dark(oklch(45% .2 265), oklch(82% .13 210));
  background: var(--surface);
}
.themed[data-scheme="dark"] { color-scheme: dark; }

light-dark() 依元素實際的 color-scheme 挑值，所以只要換一個區域的 color-scheme，裡面所有 token 就跟著換。以前要用 prefers-color-scheme 媒體查詢把每個 token 重寫一遍，手動切換時還得再寫一套 class。

不支援時

  • 淺色和深色的原始值分開存成 custom property，再用 prefers-color-scheme 媒體查詢切換同一組 token，效果相同。
  • 頁首的 <meta name="color-scheme"> 讓瀏覽器一開始就知道支援深淺色，減少畫面閃一下。
