會動的手風琴：用 ::details-content

原生的 <details>，加幾行 CSS 就有展開與收合的高度動畫。收起來的內容不是 display: none，所以頁內搜尋仍找得到，命中時會自動展開。

試試看：先全部收起，再按 Ctrl+F（Mac 是 ⌘F）搜尋「藏起來的答案」。

這個 repo 在做什麼？

把 modern-web-guidance 的新指南拆成問題線：做法、對手、退路、解鎖。

新能力和糾錯有什麼不同？

新能力讓以前做不到的事變得可行；糾錯用的是早就能用的做法，只是糾正常見錯誤。

收起來的內容找得到嗎？

找得到。這裡就是那段藏起來的答案：瀏覽器用 content-visibility 把它藏起來，頁內搜尋命中時會自動展開。

怎麼做

details::details-content {
  interpolate-size: allow-keywords;
  overflow: clip;
  transition: block-size, content-visibility, display;
  transition-duration: .3s;
  transition-behavior: allow-discrete;
}
details:not([open])::details-content { block-size: 0; }

::details-content 是 details 裡展開內容的那一塊。以前它不能被選取，要做動畫就得把 details 換成自製元件，順帶失去原生的鍵盤操作和頁內搜尋。

不支援時

  • 沒有 interpolate-size 的瀏覽器：照常開合，只是沒有動畫。
  • 系統設定減少動態效果時，直接開合。
  • 手風琴本身是原生元素，任何瀏覽器都能用。
