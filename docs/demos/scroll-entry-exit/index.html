捲動進出場：用 view()

在下面的框裡捲動。卡片捲進來時放大浮現，捲出去時縮小淡出，動畫進度直接綁在卡片在捲動區裡的位置上，捲多少就播多少，倒著捲也會倒著播。

捲動吸附讓輪播停在整張卡片上
容器查詢元件依自己的寬度換版面
錨點定位彈出層黏在觸發鈕上
檢視轉場頁面切換時元素平滑移動
:has()依子元素狀態改父元素樣式
popover不寫 JS 的彈出層
light-dark()一行定義深淺色
sibling-index()依位置錯開動畫

怎麼做

@keyframes rise-and-fade {
  entry 0%           { opacity: 0; scale: .85; }
  entry 100%, exit 0% { opacity: 1; scale: 1; }
  exit 100%          { opacity: 0; scale: .92; }
}
.card {
  animation: rise-and-fade auto linear both;
  animation-timeline: view();
}

view() 建立一條跟著「這個元素在捲動區可見程度」走的時間軸；entry、exit 分別是進場與離場那一段。以前要用 IntersectionObserver 或 scroll 監聽，每次捲動都在主執行緒算。

不支援時

  • 腳本改用 IntersectionObserver 依可見比例調整大小，效果接近，但跑在主執行緒上。
  • 系統設定減少動態效果時，卡片靜止不動。
