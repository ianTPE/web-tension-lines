錯開進場：用 sibling-index()

清單項目一個接一個滑進來。每一項的延遲由 CSS 依它是第幾個兄弟元素自己算，增加或刪掉項目也不用改程式。

    怎麼做

    .item {
  --stagger-time: 0.08s;
  animation: slide-in 0.45s both;
  animation-delay: calc(sibling-index() * var(--stagger-time));
}

    sibling-index() 回傳這個元素是第幾個兄弟（從 1 開始），乘上時間就是延遲。以前得用 :nth-child() 一條一條寫，或用 JavaScript 替每一項設樣式。

    不支援時

    • 腳本替每一項設 --sibling-index，效果一樣，只是多跑一段 JavaScript。
    • @supports 要用字面時間值（0.1s）偵測。寫成 var() 會在所有瀏覽器判成支援，退路的延遲被蓋成 0。
    • 系統設定減少動態效果時，不播放動畫。
