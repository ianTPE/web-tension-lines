誰在做
開發者（或寫程式的代理）
動作＋對象
頁面放一個 aria-live="polite" 的區塊，欄位離開或變更後延遲約 500ms 寫入「標籤：錯誤」；送出失敗時把焦點移到第一個無效欄位

戰報
勝——共用的 live region 以改變內容觸發播報，延遲讓它不會蓋過下一個欄位的朗讀（官方宣稱）

常見做法是在錯誤 <span> 上加 aria-live，然後切換它的顯示，結果時播時不播。指南改成單一播報器寫入文字；欄位修好時還要清空播報器，免得之後瀏覽頁面時又讀到舊錯誤。
