Automatic text contrast with contrast-color()

Change the background and the text picks whichever of black or white contrasts better. Useful for user-customizable labels, theme colors, or anywhere the background color isn't known in advance.

How it works

.chip {
  background-color: var(--bg);
  color: contrast-color(var(--bg));
}

Previously you converted the color to luminance in JavaScript and computed the contrast yourself, or hand-wrote a text color for every theme color. With theme switching or user-chosen colors, unreadable combinations slipped through easily.

Without support

  • Relative color syntax computes black or white in the XYZ D65 color space from the WCAG luminance threshold, with the same result. That is what this page does in browsers without support.
  • Use contrast-color() only for foreground colors such as text, never for the background.
