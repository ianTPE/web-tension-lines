Declarative buttons with command and commandfor

Say in HTML what a button does and to which element. Opening and closing a dialog takes no JavaScript at all; custom commands need just one listener instead of wiring up every button.

Archive this item?

How it works

<button commandfor="confirm" command="show-modal">Open</button>
<dialog id="confirm">
  <button type="button" commandfor="confirm" command="close">Cancel</button>
</dialog>

<button commandfor="box" command="--spin">Spin</button>
box.addEventListener("command", e => { /* e.command === "--spin" */ });

Built-in commands (show-modal, close, toggle-popover, …) need no script. Custom commands must start with --, and the listener goes on the target element because the command event doesn't bubble. Custom commands carry no built-in semantics, so toggles have to set aria-pressed themselves.

Without support

  • The invokers-polyfill is imported dynamically, and only when the browser lacks commandForElement.
  • The polyfill doesn't manage button states such as aria-expanded; add those yourself where needed.
