Opponent group chart

This chart is a module built with HTML-in-Canvas, using this repo's ledger.csv as data. The bars are drawn on the canvas, but every label is a real DOM button, so you can search, select, translate, and use the keyboard on them, and export the whole chart directly.

Pick an opponent group

Click a label in the chart, or Tab to one and press Enter, to list that group's lines here.

Try it

  • Press Ctrl+F and search for “focus”: the matches are inside the chart. Text drawn on an ordinary canvas can't be found.
  • Drag to select label text and copy it, or use the browser's translation feature on it.
  • Press Tab: focus moves through the labels in on-screen order. Sorting moves the DOM order too, so the two never drift apart.
  • “Download PNG” and “Record a 5-second video” use the canvas's existing toBlob() and captureStream(), and the output includes the label text.

Related problem lines

  • mwg:expose-canvas-content-to-browser-features: canvas content is invisible to the browser
  • mwg:export-html-media-from-canvas: export without a screenshot library redrawing the DOM
  • mwg:drag-and-drop: move real nodes when sorting, keeping visual and DOM order aligned
HTML-in-Canvas is currently supported only in Chrome 157 and later. Other browsers get a fallback: the labels are overlaid on the canvas with CSS, so search and keyboard still work, but exported images and videos don't include the label text. Data is generated from ledger.csv by scripts/build_demo.py.
