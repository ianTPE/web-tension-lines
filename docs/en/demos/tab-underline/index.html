Sliding tab underline with anchor positioning

Click a different tab and the underline slides under it. CSS anchor positioning works out the position, so there is no JavaScript measuring tab widths and coordinates, and tabs of different lengths just work.

How it works

li.active { anchor-name: --active-tab; }

ul::before {
  content: "";
  position: absolute;
  position-anchor: --active-tab;
  inset-block-start: calc(anchor(bottom) + .1lh);
  inset-inline-start: anchor(left);
  inset-inline-end: anchor(right);
  border-block-end: .2lh solid;
  transition: inset .25s;
}

The script only moves the active class and aria-current to the clicked tab; CSS handles the underline's position and animation. The underline is only a visual cue, so the current tab still needs aria-current for assistive technology.

Without support

  • The active tab gets its own border-bottom instead. The underline is still there; it just doesn't slide.
  • When the system asks for reduced motion, the underline jumps straight to its new position.
