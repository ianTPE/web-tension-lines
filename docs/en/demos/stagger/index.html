Staggered entry with sibling-index()

List items slide in one after another. CSS works out each item's delay from its position among its siblings, so adding or removing items needs no code changes.

    How it works

    .item {
  --stagger-time: 0.08s;
  animation: slide-in 0.45s both;
  animation-delay: calc(sibling-index() * var(--stagger-time));
}

    sibling-index() returns the element's position among its siblings (starting at 1); multiply it by a time to get the delay. Previously you wrote one :nth-child() rule per item, or set styles on each item from JavaScript.

    Without support

    • A script sets --sibling-index on each item. The effect is the same, at the cost of running some JavaScript.
    • Detect support in @supports with a literal time (0.1s). Using var() there reports support in every browser and resets the fallback delay to 0.
    • When the system asks for reduced motion, nothing animates.
