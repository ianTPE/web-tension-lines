Light and dark tokens with light-dark()

Each color token holds its light and dark values in one line. Switch the options below and the whole panel's background, text, brand color, and form controls change together, without two stylesheets or a pile of media queries.

Every color in this panel comes from a light-dark() token.


How it works

:root { color-scheme: light dark; }

.themed {
  --surface: light-dark(#fff, #1b1d22);
  --brand: light-dark(oklch(45% .2 265), oklch(82% .13 210));
  background: var(--surface);
}
.themed[data-scheme="dark"] { color-scheme: dark; }

light-dark() picks a value from the element's actual color-scheme, so changing one region's color-scheme switches every token inside it. Previously you rewrote every token in a prefers-color-scheme media query, and added yet another set of classes for a manual toggle.

Without support

  • Store the raw light and dark values as custom properties, then switch the same tokens with a prefers-color-scheme media query, with the same result.
  • The <meta name="color-scheme"> in the head tells the browser early that both schemes are supported, reducing the flash on load.
