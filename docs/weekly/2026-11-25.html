這週的對手

「重複出現」指跨週累計至少 3 條線的組（數字為有效線，含本週）。本週沒有新開對手組。

  • 新屬性的隱藏前提（19，重複出現）——mwg:teaser:4、mwg:teaser:6、mwg:teaser:7：backdrop-filter 看似一行就好，其實要放在遮罩元素外面、比淡出晚開始、半徑夠小，少一個條件就沒效果或露餡。
  • 裁切切掉不該切的（8，重複出現）——mwg:teaser:5：濾鏡只在自己的框裡畫，暈開的部分被切成直線。
  • 沒防護不支援的瀏覽器（7，重複出現）——mwg:teaser:8：SVG 濾鏡的模糊在 Safari、Firefox 完全沒有效果。
  • 視覺隱藏卻仍可觸及（8，重複出現）——mwg:teaser:3：淡掉的連結看不清卻仍能聚焦。
  • 版面依賴錯的量測（17，重複出現）——mwg:teaser:2：淡出長度用百分比，跟著內容變長。
  • 手工重現瀏覽器渲染（5，重複出現）——mwg:teaser：用半透明疊層假造淡出（指南沒給具體後果，對手缺）。
  • 版面意外溢出或位移（32，重複出現）——mwg:context-menu：手算座標的右鍵選單不處理溢出。
  • 隱藏或停用把人擋在外面（36，重複出現）——mwg:context-menu:2：動作只放右鍵選單，iOS Safari 長按打不開。
  • 彈出層脫離觸發點（10，重複出現）——mwg:context-menu:3：同一選單多個入口，要依來源擺位置（對手缺）。

僵持中的線

本週新拆的 11 條沒有「僵持」（勝 3、部分改善 8）。既有的 mwg:security:8（Document-Isolation-Policy）仍是僵持：Firefox、Safari 不支援。

本週靈感

本週新能力 3 條：mwg:context-menu、mwg:context-menu:3、mwg:teaser:4。以下點子（非指南原文）和 ledger 裡的舊線組合。

  1. 可以對任何東西按右鍵的看板——給自己排工作的人用；卡片、欄位標題、空白處各有右鍵選單，手機改按「⋯」，打開的是同一份選單。
    - 用到：mwg:context-menu（零尺寸錨點、position-try）、mwg:context-menu:2（可見按鈕）、mwg:context-menu:3（ToggleEvent.source）、mwg:custom-button-actions（--archive 這類自訂指令）
    - 限制：錨點定位、Invoker Commands、ToggleEvent.source 都是 Newly。沒有錨點定位時退回手算座標，靠邊會溢出；沒有 source 時要在各觸發點設位置
    - 小 demo：三張卡片，每張一個選單和一顆「⋯」，在視窗四個角落按右鍵看它翻面
  2. 地圖或樓層圖的就地標註——帶人看場地、做田野紀錄的人用；在圖上任一點按右鍵開「新增標點」選單，滑過既有標點時出現說明卡，兩者互不關掉。
    - 用到：mwg:context-menu（游標處選單）、mwg:hovercard:2（popover="hint"）
    - 限制：popover="hint" 是 Limited（Safari 未支援），退回 manual 後要自己在離開時關卡片；觸控裝置要另給一顆「新增標點」按鈕
    - 小 demo：一張平面圖圖片，右鍵加點，點存在 localStorage
  3. 會員文章的試閱結尾——寫電子報、賣課程講義的人用；伺服器只送前幾段，最後五行漸漸變淡又變糊，底下接訂閱鈕。
    - 用到：mwg:teaser:4（外層 backdrop-filter），照 mwg:teaser:2、:5、:6、:7 的條件調長度與外伸
    - 限制：backdrop-filter 是 Newly，不支援時只淡出不模糊；模糊擋不住複製與讀屏，後面的內容一定要在來源端截斷
    - 小 demo：一篇長文，深淺兩種背景各一份，檢查兩側沒有切邊、起點沒有變黑的帶子
  4. 滑過就試穿的右鍵樣式選單——做簡報或海報編輯器的人用；在物件上按右鍵開樣式清單，滑過任一項先預覽，離開就還原，點下去才套用。
    - 用到：mwg:context-menu（游標處選單）、mwg:interest-triggered-action-previews（interestfor）
    - 限制：Interest invokers 是 Limited（僅 Chromium 149），其他瀏覽器靠 polyfill；指南 v1.0.2 也提醒預覽不能是唯一取得資訊的途徑
    - 小 demo：一個方塊、四種配色，右鍵選單滑過換色、點擊定案

既有線的變更

  • mwg:security:8：上游改以 COOP＋COEP 為跨瀏覽器預設、Document-Isolation-Policy 為替代，原對手引文被改寫，改引新句並補上跨來源 iframe 也要啟用 COEP；支援資料由「Chrome 142+」改為 Chrome／Edge 137（仍 Limited），戰報仍為僵持
  • mwg:anchor-positioning-tab-underline：上游新列「錨點動畫」的支援（Limited，Firefox 不支援），支援狀態由 Newly 改為 Limited；對手改引新句，做法改用 anchor(self-start)／anchor(self-end)；戰報仍為部分改善
  • mwg:anchor-positioning-tab-underline:2：同上，支援狀態由 Newly 改為 Limited，退路句改為「不能過渡時直接跳到新分頁」；戰報不變
  • mwg:menu、mwg:menu:6：Invoker Commands 的退路由腳本／click 監聽改為 popovertarget，退路句跟著改，分類與戰報不變
  • 只更新細節：mwg:app-menus（支援段由群組狀態改為 position-area 的 Newly，經過一併更正）、mwg:menu:2、mwg:toolbar:2（同一支援描述）。menu.md 線尾的提醒也更正：上游反轉說法，現在要求不要覆寫 focusVisible
  • 上游已刪除：mwg:soft-edge-content-fade（visual-design/soft-edge-content-fade.md），ledger 狀態改為「上游已刪除」，線檔保留。同主題由新的 teaser 接手，但舊指南對疊層的具體說法（要知道背景色、擋文字選取）沒有搬過去

給使用者的提醒：

  • 依規則沒拆、但值得看的兩段：這兩份指南已有線檔，規則只准改既有線，所以新段落沒有拆成新線。

- webmcp/agentic-javascript-tools.md 新增 outputSchema（Chrome 159 起）：宣告工具回傳值的結構；execute 回傳的 { error } 若不在 schema 裡，代理可能只收到工具錯誤、看不到訊息。這是新能力 - security/security.md 新增 1.6 WebSocket：瀏覽器不對 WebSocket 握手執行 CORS，仍會帶上符合條件的 cookie，所以伺服器要驗 Origin - 若要拆，請調整 PROMPT.md「已有線檔」那條規則

  • Anchor positioning 的偏差規則：v1.0.2 已有 app-menus、menu、navbar、toolbar、anchor-positioning-tab-underline 改用個別屬性的狀態（Newly），但新的 context-menu 仍寫群組狀態，所以規則還不能退役。另外 tab-underline 的「動畫」是獨立的 Limited，不適用那條偏差
  • 上游程式碼問題（未回報）：context-menu.md 的退路範例寫 !'source' in ToggleEvent.prototype（條件永遠為假）與 popover.style.setAttribute(...)（沒有這個方法），照抄不會生效；dialog.md 新句 "ensure that focused elements are completely obscured by the non-modal dialog" 看起來漏了 not
