新開組的拆分理由依形狀歸納如下：

  • 平台能力邊界：頁面功能對代理不透明、邊界往返吃掉效能、移植時沿用原生假設、裁切只有硬邊、動畫曲線只有簡單形狀；這些不是一般 JS、CSS 或資安問題，而是新 API 的能力與移植限制。
  • 互動與可及性：回饋落後於手勢、原生捲動手勢不合用途、動作被意外觸發、可及名稱蓋掉可見文字、浮層遮住說明；共同點是使用者看得到或操作到的狀態，和程式／輔助技術回報的不一致。
  • 樣式與版面：主題配色對不上、圖示樣式管不到、簡寫或屬性連動重設、繼承範圍不符預期、堆疊脈絡改變層級；把原先過寬的層疊與版面組拆成可辨認的機制。
  • 資料、時間與安全：時間模型失真、防線形同虛設、封裝邊界切斷關聯、押注不會普及的功能；分別處理曆法與時區、看起來有防護卻無效、shadow 邊界，以及不會跨瀏覽器普及的做法。
  • 效能與資源：捲動連動效果靠JS監聽、內容要等JS才成形、工作花在看不到的地方、效能量測失真或有盲點；把主執行緒、渲染時機與量測盲點分開，不再全塞進「效能」。

本週靈感

本週新能力 181 條。以下 5 個是發想，不是指南宣稱；都把支援限制與退回時會失去的東西列出。

  1. 表單直接變成瀏覽器代理的搜尋工具
    給查庫存、找文件的使用者：現成搜尋表單加 WebMCP metadata，代理代填、人按送出，不必另架 MCP server。
    用到：mwg:webmcp、mwg:agentic-forms、mwg:agentic-javascript-tools、mwg:agentic-forms:2。
    限制：目前只有 Chromium 146 旗標預覽；其他瀏覽器忽略工具屬性，只保留一般表單。高風險動作仍要人工確認。
    小 demo：一個三欄商品搜尋表單，註冊查詢工具，代理填關鍵字與類別，使用者確認後顯示結果。
  2. 像原生 app 一樣可滑回的檔案總覽
    給行動版文件或設定頁：列表鑽入詳情時保留堆疊，返回手勢跟著手指走，搬動目前頁面不丟表單狀態。
    用到：mwg:stack-drill-down、mwg:stack-drill-down:12、mwg:move-dom-element-without-losing-state、mwg:platform-controls-dismiss-dialog。
    限制：部分轉場與捲動功能 Limited／Newly；不支援時退回一般即時切頁與瀏覽器返回，失去手勢連動與狀態保留。
    小 demo：三層「資料夾→文件→編輯」頁面，左右滑返回，輸入到一半的內容在來回後仍在。
  3. 不上雲的客服工單分類器
    給有隱私需求的內部工具：在本機把工單分成固定類別與優先級，直接輸出 JSON 寫入表單。
    用到：mwg:language-model、mwg:language-model:10、mwg:language-model:11、mwg:language-model:17。
    限制：Prompt API 僅 Chrome 148，且有 22 GB 空間與記憶體門檻；其他瀏覽器退回伺服器 API 或人工分類，失去離線與資料不離機的好處。
    小 demo：貼一段工單後輸出 {category, priority}，相同輸入讀快取，Schema 驗證後填入兩個欄位。
  4. 繁中長文閱讀器
    給技術文件與新聞站：中日文底線避開筆畫，網頁字型與退路等大，標題自動平衡換行。
    用到：mwg:custom-text-decorations:3、mwg:visually-stable-font-fallbacks、mwg:visually-stable-mixed-fonts、mwg:typography:6。
    限制：text-decoration-skip-ink、字型調整與 text-wrap 支援不一；退回時仍可讀，但可能遮筆畫、換字跳動或留下孤字。
    小 demo：同一篇繁中長文切換兩套網頁字型，顯示連結底線、行內程式碼與卡片標題，記錄 CLS。
  5. 捲動即時回饋的教學導覽
    給長篇操作教學：目前步驟與捲動位置同步，按下一步會等真正的捲動完成再前進。
    用到：mwg:scroll-snap-realtime-feedback、mwg:scroll-completion-effects、mwg:scrollspy、mwg:scroll-snap-state-sync。
    限制：scroll snap events、promise 與 :target-current 多為 Limited；不支援時退回 IntersectionObserver／scroll listener 與「點了就換」，失去原生即時性。
    小 demo：五步驟教學，左右欄分別顯示目前步驟與進度，快速連按下一步不會搶在捲動途中連跳。
